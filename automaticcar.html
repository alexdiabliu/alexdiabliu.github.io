Embedded autonomy stack for sensing, control, and movement logic.

Overview / Background

This autonomous car project explores embedded decision-making for navigation, obstacle awareness, and motion control under constrained hardware resources.

Technologies Used

The implementation combines microcontroller control, sensor integration, and software logic for path planning and actuation response across a prototype vehicle platform.

Challenges Faced

Primary challenges included reliable sensor fusion, low-latency control loops, and maintaining stable behavior under changing environmental conditions.

Project Demonstration

The codebase demonstrates the control architecture and embedded interfaces required to move from command logic to physical autonomous behavior.
